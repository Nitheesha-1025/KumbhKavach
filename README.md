# KumbhKavach
Kumbh Kavach is an AI-powered, offline-first platform for Simhastha Kumbh Mela 2027. It predicts crowd-crush risk from CCTV and drone feeds, sends one-tap SOS via SMS or PWA to the nearest medical help, reunites lost pilgrims through consent-based matching, and dispatches MyBharat volunteers, with voice-first multilingual support.
